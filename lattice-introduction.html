TRACK / 01 — SYSTEMS & DATA

Backend Management

Run systems that don't page you at 3 a.m.

Design a schema for a real order pipeline, then load-test it until it begs for mercy. By review three you'll read EXPLAIN plans like weather reports.

WEEK 1–3 · 3 MENTOR REVIEWS

Build three services that talk over gRPC, fail independently, and restart without anyone noticing. Boring is a compliment here.

WEEK 4–6 · PAIR-PROGRAMMED

Define a contract, break it on purpose, watch the linter catch you. Then stream 100k events and keep p99 under 40 ms.

WEEK 7–9 · LOAD-LAB ACCESS

Instrument everything you've built, carry a practice pager for one week, and write the postmortem you hope you'll never need.

WEEK 10–12 · ON-CALL DRILL

Containerize the whole stack, deploy blue/green, and break production in a controlled, safely chaotic final drill.

WEEK 13–16 · FINAL REVIEW

02 — The Studio

A studio, not a school.

Lattice started in a Berlin garage in 2016 — four engineers who kept hiring juniors who'd been taught everything except how to ship. So we built the place we wished existed: members learn inside real product teams, on code that clients run in production.
